# Student Academic Performance Prediction using Machine Learning

- **Project Name:** Student Academic Performance Prediction
- **Team Member:** Sandip (@sandip-098)
- **Course:** BCA Semester VI (P.K. Royal Memorial College)

## Overview
This project uses Machine Learning classification algorithms (Decision Tree, Random Forest, Logistic Regression, Perceptron, and MLP) to analyze student academic performance data and predict performance classes (Low, Medium, High).
