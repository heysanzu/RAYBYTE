# What are we solving?
RAYBYTE builds a classifier pipeline over a real-world student dataset, trains multiple ML models, then surfaces the most predictive features through confusion matrices, heatmaps, and importance plots.

---

## Grade Prediction (AI & ML)

This is a machine learning project that uses classification algorithms to predict the factors most heavily affecting student grades, utilizing data from a CSV file.

The dataset features student demographics (such as nationalities and grade levels) alongside key behavioral determining factors, including the number of hands raised in class, attendance records, and total hours studied.

We implemented and compared various classifiers and ML models to achieve the most accurate predictions regarding which specific variables impact student performance.
